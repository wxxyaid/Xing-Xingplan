# 星星计划记录规则

## 当前工作方式

星星计划采用“先聊天，后归档”的方式，不要求每次聊天内容都立即写入 GitHub。

### 1. 平时正常聊天
日常交流、想法、计划、尝试、失败和变化，先自然聊天，不实时打断去做 GitHub 记录。

### 2. 由用户明确触发归档
只有当用户明确表示“把今天的谈话记录到 GitHub”“总结进星星计划”“把这一段归档”等意思时，才进行本次 GitHub 更新。

### 3. 归档时整理而不是照抄
归档时由 ChatGPT 对当天或当前阶段的对话进行总结，提炼真正值得长期保留的内容，包括：
- 发生了什么
- 当前想法和状态
- 做出的决定
- 新的计划或变化
- 重要时间节点
- 值得以后回看的细节

### 4. 每次归档附带 AI 观察与评价
除客观总结外，每次正式归档可以加入一段“AI 观察与评价”，包括：
- 当前执行情况
- 计划是否现实
- 哪些地方有进步
- 哪些地方存在反复、中断或风险
- 与之前相比发生了什么变化
- 对下一阶段的判断

评价应尽量客观、具体，不刻意夸奖，也不因为一次中断就做负面定性。

### 5. 聊天中不必逐字重复评价
归档完成后，聊天里只需简要说明已经完成归档；除非用户主动询问，不必把 GitHub 中的“AI 观察与评价”逐字重复出来。

### 6. 后续继续补充规则
本文件只记录目前已经确定的规则。后续讨论出的新规则继续追加或修订到这里。
